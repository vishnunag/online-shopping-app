# 🛍️ Online Shopping Web Application

A full-stack e-commerce platform built using Django. It supports user registration, product browsing, cart management, and order placement. The project is built as a learning exercise to understand web development with Django and front-end technologies.

---

## 🚀 Features

- ✅ User Authentication (Login/Signup)
- 🛒 Add to Cart, View Cart, and Remove Items
- 📦 Place Orders with Order Summary
- 🧾 Order Tracking System
- 💻 Responsive UI using HTML and CSS
- 🔐 Secure routing for authenticated pages

---

## 🛠️ Tech Stack

- **Backend**: Django, SQLite
- **Frontend**: HTML, CSS, JavaScript
- **Tools**: VS Code, Git, Thunder Client
